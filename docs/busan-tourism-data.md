# 부산 관광명소 데이터

REPORT의 기존 관광 자원 조사 카드 아래에 부산광역시 부산명소정보 서비스 목록을 추가했습니다. 명소 이름·주소·소개문 검색, 구·군 필터, 12개씩 더 보기, 개별 상세 안내(교통·운영시간·요금·연락처·휴무일·편의시설), 지도 및 시설 홈페이지 이동을 제공합니다. 원본에 없는 필드는 정보 미제공으로 표시합니다.

공식 출처: https://www.data.go.kr/data/15063481/openapi.do

요청 주소(키 미포함): https://apis.data.go.kr/6260000/AttractionService/getAttractionKr

현재 공식 카탈로그는 결과 필드를 resultCode로 설명하지만 실제 JSON은 header.code를 사용해 두 형태를 처리합니다. 항목 수와 중복 ID를 검증하고 전체 페이지 수집을 완료한 경우에만 공개 스냅샷을 생성합니다.

## 키를 공개하지 않는 방식

- `.env`의 `BUSAN_TOURISM_API_KEY`는 로컬 Node 수집기만 읽습니다.
- GitHub Pages와 브라우저에서는 API를 직접 호출하지 않습니다. 공개 필드만 허용한 JSON/JS 스냅샷을 읽습니다.
- 로그에는 키, 인증 요청 URL, 원본 API 응답, 예외 스택을 출력하지 않습니다.
- 원본 응답이나 `.env` 사본을 저장하지 않습니다. `.env*`와 키 등록 임시 파일은 .gitignore로 제외합니다.
- 수집기는 공개 산출물에 키가 포함되지 않았는지 검사한 뒤 저장합니다. API key를 CLI 인자로 전달하지 마세요.

## 로컬에서 갱신

프로젝트 폴더의 터미널에서 실행합니다(Node 22 이상).

```powershell
node scripts/fetch-busan-tourism.mjs
```

등록된 키에 해당 서비스의 활용신청 권한이 필요합니다. 외부 통신이 허용된 로컬 환경에서 실행합니다. API는 100개씩 조회하며 인증키의 인코딩 여부를 처리합니다. 실패 시 출력되는 안전한 상태 코드만 확인하고 키나 인증 URL을 채팅에 보내지 마세요. 데이터 수집 실패 시 기존 스냅샷을 먼저 삭제하지 않습니다.

생성 파일:

- `assets/data/busan-tourism.json`: 공개 데이터와 수집 시각·출처
- `js/busan-tourism-data.js`: file:// 및 정적 호스팅을 위한 동일 데이터 JS

성공 후 위 두 공개 데이터 파일만 검토·커밋·push하면 Pages에 반영됩니다. 브라우저에서 이전 결과가 캐시될 때는 새로고침합니다. `.env`는 커밋하지 않습니다. 로컬 수집은 별도 예약 없이 명령 실행 시 갱신되며, 원본 서비스가 실시간 제공하더라도 웹페이지는 마지막 수집 기록을 표시합니다.

원격 이미지가 없거나 로딩에 실패하면 자리 표시를 유지합니다. 지도 링크는 장소명/주소 검색이며 주소 정확도를 보장하는 실측 좌표 표시는 아닙니다. 상세 정보는 원문에서 제공된 안내이며 방문 전 해당 시설의 최신 공식 안내를 확인해야 합니다.
