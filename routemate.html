01 / PROJECT NOTE

저장은 쉬운데,
계획은 어려우니까.

인스타그램에서 저장한 카페, 블로그에서 발견한 맛집. 흩어진 장소를 다시 찾고 이동 순서를 정한 뒤 예약 앱까지 오가는 번거로움에서 출발했습니다. RouteMate는 장소 수집부터 동선 설계, 예약과 티켓 확인까지 하나의 흐름으로 연결합니다.

02 / KEY FEATURES

내 취향대로,
한눈에 계획하기.

여행지를 발견하는 순간부터 현장에서 티켓을 꺼내는 순간까지. 네 가지 핵심 경험으로 연결했습니다.

01 / AI ROUTE

저장한 장소를 여행 코스로

SNS 링크에 담긴 장소를 바탕으로 이동 시간, 교통수단, 체류 시간을 고려한 코스를 제안합니다. 취향과 예산에 맞는 세 가지 선택지를 비교하며 나만의 일정을 만들어 갑니다.

장소 수집 · 맞춤 코스 비교
02 / BOOKING HUB

여행 동선에 맞춰 예약까지

일정의 마지막 장소와 체크인 시간을 고려한 숙소, 항공권, 맛집 원격 줄서기를 한곳에서 살펴보는 예약 센터입니다. 계획과 예약 사이의 번거로운 이동을 줄이는 경험을 설계했습니다.

호텔 · 항공 · 맛집 대기표
03 / TICKET WALLET

필요한 티켓을 한곳에

항공권, 호텔 바코드, 맛집 대기표를 모아 필요한 순간에 꺼내 봅니다. 다가오는 예약과 사용을 마친 티켓을 구분해 여행 전후의 기록까지 이어 갑니다.

모바일 티켓 · 사용 이력
04 / UPCOMING TRIP

다가오는 여행을 첫 화면에

출발일까지 남은 날짜와 다음 예약을 홈에서 확인합니다. 여러 메뉴를 찾지 않아도 예약 정보와 모바일 바코드를 바로 열 수 있도록 구성했습니다.

D-Day · 예약 위젯 · 바로 확인

04 / HOW IT WORKS

여행 준비의 흐름.

  1. 01

    장소 선택

    가고 싶은 장소를 추가하고 목록을 정리합니다.

  2. 02

    조건 설정

    시간, 예산, 취향과 이동 방식을 선택합니다.

  3. 03

    코스 비교

    세 가지 제안의 방문 순서와 예상 일정을 비교합니다.

  4. 04

    마이트립 확인

    선택한 코스의 타임라인과 장소 정보를 확인합니다.

05 / PROJECT BUILD

기획부터 구현까지.

여행자의 준비 과정을 기준으로 화면과 데이터 흐름을 설계하고, AI 프롬프트와 프론트엔드·백엔드를 함께 구성한 개인 프로젝트입니다.

  • React · TypeScript
  • Tailwind CSS · Lucide
  • Google Gemini API
  • Node.js · Express
  • Supabase · PostgreSQL 설계
  • Cloud Run 배포 아키텍처
UX / MOBILE FIRST

작은 화면에서도 편하게

375~430px 모바일 화면을 기준으로 주요 버튼과 정보의 우선순위를 정리했습니다. 바코드·QR 모달을 통해 현장에서 필요한 티켓을 바로 확인하는 흐름을 구성했습니다.

DATA / STATE & SCHEMA

예약 전후를 잇는 데이터

예약 확정과 사용 완료 상태를 구분하고, 프로필·장소·여행·예약·쿠폰의 다섯 도메인을 중심으로 관계형 데이터 구조를 설계했습니다. Supabase의 접근 제어와 실시간 데이터 구성을 고려했습니다.

기술 구성과 설계 설명은 프로젝트 소개 기준입니다. 위 체험판은 제공된 React 소스를 정적으로 실행하며 AI 서버·데이터베이스·예약 사업자에는 연결되지 않습니다.
