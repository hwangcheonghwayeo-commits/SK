# Tourism Content Archive

SK플래닛 관광 콘텐츠 제작 과정과 결과물을 정리하는 반응형 웹사이트입니다.

## 페이지

- `index.html`: 소개 및 메인 랜딩
- `report.html`: 관광 자원 조사와 기획 자료
- `contents.html`: 카드뉴스와 영상 아카이브
- `sns.html`: SNS 콘텐츠 분석 대시보드
- `final.html`: 최종 팀 프로젝트

## 콘텐츠 교체 위치

- 메인 배너 및 소개 이미지: `assets/images/home/`
- 관광 자원 이미지: `assets/images/report/`
- 카드뉴스 및 썸네일: `assets/images/contents/`
- 최종 프로젝트 이미지: `assets/images/final/`
- 영상: `assets/videos/`
- SNS 분석 데이터: `assets/data/`

이미지를 추가한 뒤 각 HTML 파일의 `.placeholder` 요소를 `<img>` 또는 `<video>` 요소로 교체하면 됩니다.

## 실행

별도의 빌드 과정 없이 `index.html`을 브라우저에서 열어 확인할 수 있습니다. 데이터 파일을 불러오는 기능을 추가할 경우 로컬 웹 서버 사용을 권장합니다.

## 서비스 포트폴리오

- `routemate.html`: RouteMate 서비스 소개 및 조작 가능한 체험판
- `css/pages/routemate.css`: 서비스 소개 페이지의 반응형 스타일
- `routemate-demo/`는 제공된 React 앱의 정적 빌드입니다. 실제 AI·DB·결제 연결 없이 예시 데이터를 사용합니다. 원본 AI Studio 서비스는 별도 링크로 열 수 있습니다.
