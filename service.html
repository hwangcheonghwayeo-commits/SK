03 / PROJECT NOTE

저장은 쉬운데,
계획은 어려우니까.

인스타그램에서 저장한 카페, 블로그에서 발견한 맛집. 흩어진 장소를 다시 찾고 이동 순서를 정한 뒤 여러 예약 앱까지 오가는 번거로움에서 시작했습니다. RouteMate는 발견한 장소를 실제 여행 일정으로 바꾸는 전 과정을 매끄럽게 이어 줍니다.

04 / USER FLOW

계획은 짧게,
여행은 가볍게.

가고 싶은 장소를 찾은 순간부터 현장에서 티켓을 꺼내는 순간까지의 핵심 흐름입니다.

  1. 01

    장소 모으기

    SNS 링크와 캡처 속 장소를 보관함에 추가합니다.

  2. 02

    조건 설정

    여행 시간, 예산, 취향과 이동 방식을 선택합니다.

  3. 03

    코스 비교

    AI가 제안한 세 코스의 동선과 일정을 비교합니다.

  4. 04

    여행 시작

    예약 정보와 모바일 티켓을 한곳에서 확인합니다.
